# 次の目標: AMPが自然言語より優れる条件を実験で見つける

## これまでの実験の流れ

```
① Gemini blind test        → AMPを知らなくても意味を復元できる
② Independent implementation → 仕様書だけから別実装を作れる(3回とも22/22)
③ Minimal form experiment   → かなり小さい構造でも会話が成立する
                               (ただし曖昧さが出ると追加構造が必要になる)
```

3つとも「AMPは動く」ことは示したが、**「AMPを使う方が自然言語だけより良い」ことは
一度も示していない**。v1.0-goal.mdの目標(AI同士がAMPのJSONだけで会話を成立させる)
はPhase 1・2で既に達成済みだが、これは存在意義の証明にはなっていない。

## 決定: 目標を置き換える

**旧目標(v1.0-goal.md)**: 「AI間通信プロトコルを完成させる」
**新目標**: 「AI間の意味伝達において、AMPが自然言語より明確になる条件を実験で見つける」

最終形として据える基準:

> **AMPを知らない2つのAIが、AMPを介して複数ターン会話し、自然言語だけの場合よりも
> 意味の取り違えを減らせることを実証する。**

これが実証できて初めて、v1.0(動くこと)からv2.0(必要であること)に進める。今は
「完成させる段階」ではなく「AMPが本当に必要になる境界を探す段階」だと位置づける。

## 実験計画

### 実験A: 完全往復(意図保持の検証)

```
AI-A: 自然言語で意図を持つ
  → その意図をAMPに変換
    → AI-B: AMPだけを受け取り、自然言語で解釈
      → その解釈に基づき応答をAMPで生成
        → AI-A: AMPを自然言語で再解釈
```

3〜5ターン。単に会話が成立したかではなく、**各段階の自然言語(意図原文/AI-Bの解釈/
AI-Aの再解釈)が意味的に一致しているか**を見る。情報のロスがどこで起きるかを追跡する。

### 実験B: 壊す(曖昧な自然言語での比較)

自然言語なら曖昧になる入力を用意する。例:
- "Send the file to Alex after he finishes reviewing it."(heの指示対象が曖昧)
- "Don't send the file until Alex confirms it."(否定+条件)

同じシナリオを (1) 自然言語のみでAI-A↔AI-Bにやらせる版 と (2) AMPを介して
やらせる版 の両方で実施し、意味の取り違えが起きるかを比較する。

**予想される結果**: 現在のAMPは論理関係(条件・因果・否定+条件の複合)を表現する
構造を持たない(gap-analysis項目7・8、ADR-024により実例が出るまで先送り中)。
この実験は「表現できない」という結果が出ること自体が価値のあるデータになる——
それはgap-analysis 7・8番に初めての実例を与える。

## 仕様追加のサイクル(歯止め)

実験で問題が見つかったときだけ、以下のループで対応する。ADR-024の精神をそのまま
手続き化したもの:

```
問題発生(実験で表現できない/誤解される)
  → 既存の最小構造で表現できるか再確認
  → できない
  → 新フィールドを設計
  → 削除実験(minimal-form-experimentと同じ手法)で本当に必要か検証
  → 仕様化
```

先回りでの拡張(「こういうケースもあり得るから」)はしない。実験でしか着手しない。

## この目標を覆すべき条件

なし。実験Bで「自然言語で十分、AMPは負ける」という結果が繰り返し出た場合は、
AMPの適用範囲(用途)を狭めて再定義する契機として扱う——それも有効な結果である。

## 実施記録(2026-09-13)

計画時点の実験A・Bに加え、ユーザー提案で実験C(同一意味・別表現の収束性)・
D(逆方向の曖昧性破壊、簡易)・E(条件節の削除実験)を追加実施した。

| 実験 | 結果 | 記録 |
|---|---|---|
| A: 完全往復 | 情報のロスは変換の入口(urgency)で1箇所のみ、伝達4回は無誤読 | [experiment-a-intent-roundtrip.md](experiment-a-intent-roundtrip.md) |
| B: 情報種別ごとの比較 | 条件節(until/after)が想定より支配的な欠落として2ケースとも露呈 | [experiment-b-comparison-matrix.md](experiment-b-comparison-matrix.md) |
| C: 同一意味・別表現 | 4つの言い回しがAMP化で100%同一構造に収束、丁寧さは混入せず | [experiment-c-convergence.md](experiment-c-convergence.md) |
| D: 時間節の曖昧性(簡易) | Bと同じ結論(time roleが無く"after the meeting"が丸ごと脱落) | 会話内のみ、Eに直結 |
| E: 条件節の削除実験 | `condition`構造の有無でAIの自己評価が「判断不可」→「判断可能」に反転 | [experiment-e-condition-structure.md](experiment-e-condition-structure.md) |

**総合的に見えてきたAMPの性質**: 自然言語のうち`act`/`predicate`/`roles`が表す
次元(誰が誰に何をするか)は表現の揺れを吸収して同じ構造に収束する(C)。
それ以外の次元(urgency、条件節)は現状のスキーマに受け皿が無く、変換の入口で
正直に失われる(A・B・D)。ただし条件節については、最小限の構造(`condition`)を
足すだけで意味の一意性が回復することを削除実験で確認した(E)——これは
ADR-024が要求する「実例」の条件を満たした初めてのケースであり、次のADR
(仮称ADR-026)候補になる。

未実施: pronoun照応の純粋な再実験、自然言語有利ケースの追加(ユーザー優先順位
表の4・5番)。

### 追記: F-2・Gの実施結果(2026-09-13)

| 実験 | ケース数 | 結果 | 記録 |
|---|---|---|---|
| F-2: 表現揺れ・参照揺れ耐性 | 4 | 自然言語1/4正解・AMP実質4/4正解。正解率自体に差 | [experiment-f2-reference-stability.md](experiment-f2-reference-stability.md) |
| G: 参照の長期安定性 | 1(試行錯誤含む) | 正解率同じ(1/1)だがconfidence中程度→高い、複数解釈あり→なしに差 | [experiment-g-longterm-reference.md](experiment-g-longterm-reference.md) |

Gでは2回の設計ミスを経験し、両方とも正直に記録した——(1)質問が狙った曖昧性を
実際には要求していなかった、(2)自然言語側にAMPで表現不可能な条件節を紛れ
込ませてしまい、「entity参照の一意性」ではなく「条件節の欠如」という別の
弱点を測ってしまっていた。3回目でようやく「直近性 vs 動詞の意味的対応」を
競合させる設計に成功し、実験Fケース1と同じパターン(正解率同じ、confidence/
曖昧性に差)を独立に再現した。

**現時点での結論(3件のケース群から)**: 「複数の候補entityが存在し、
自然言語では会話文脈や指示語に依存して対象を特定する必要がある状況」で、
AMPは自然言語より高い確信度・低い曖昧性で意味を保持する。これは1件の
偶然ではなく、独立した3つの実験群(F・F-2・G)で再現した。ただし条件節・
urgency・ニュアンスの領域では逆にAMPが劣ることも実験A・B・Dで確認済み
——**AMPが自然言語を代替するのではなく、棲み分けが存在する**、という
仮説がかなり具体的な形で裏付けられてきている。

### 追記: 難易度スケーリングとモデル横断検証(2026-09-13)

その後、[experiment-level-difficulty-scaling.md](experiment-level-difficulty-scaling.md)
で候補数(2〜4)と競合の有無を分離したところ、**差を生むのはentity数では
なく「手がかりの競合」であること**が判明。さらに
[experiment-cross-model-verification.md](experiment-cross-model-verification.md)
でこの最小構成をSonnet・Geminiの2モデルで再現し、**entity参照の一意性
(A・B軸)は両モデルで完全に同じパターンを示した**——競合なしは両条件
正解、競合ありはNLのみ崩れAMPは正解を維持。これは特定モデルの癖ではなく
再現性のある性質だと言える。

**現時点で最も精緻化された仮説**:

> AMPが自然言語より優れるのは、情報量・会話の長さ・entity数それ自体では
> なく、**自然言語による参照解決に複数の競合する手がかりが存在し、その
> うち表面的な手がかり(直近性など)が正解と一致しない状況**においてで
> あり、これは少なくとも2つの異なるAIモデルで再現する構造的な性質である。
