# 実験F-2: 表現揺れ・参照揺れ耐性

実験Cは「AMP生成側が4つの言い回しを同一構造に収束させるか」を見た。F-2は
一歩進めて、**その収束した構造がAI-B側の解釈安定性にもつながるか**を見る。
実験Fケース1と同じ背景(file.a/file.bの両方を過去に話題にした、順序の記憶なし)
のもとで、AI-Aの同一の意図(file.aが欲しい)を4通りの自然言語表現でB役に渡し、
解釈のばらつきを測定した。

## 4バリアント(全てSonnet)

| # | 自然言語 | INTERPRETED_FILE | CONFIDENCE | MULTIPLE_INTERPRETATIONS |
|---|---|---|---|---|
| 1 | "Send file.a to AI-A."(明示的) | file.a | 高い | いいえ |
| 2 | "Please send AI-A the file we discussed first." | **判定不能** | 低い | はい |
| 3 | "Could you forward that file to AI-A? You know, the one we mentioned earlier." | **判定不能** | 低い | はい |
| 4 | "I need the file delivered to AI-A, not the other one." | **判定不能** | 低い | はい |

対応するAMP版(実験Fケース1で取得済み): `patient.refs=["entity:file.a"]`を
明示 → INTERPRETED_FILE: file.a / CONFIDENCE: 高い / MULTIPLE: いいえ。

## 発見: 自然言語の失敗モードは1種類ではなかった

実験Fケース1では、B役は"that first file"という曖昧表現に対して**file.aを
推測して結果的に正解**した(ただし自己申告のconfidenceは低かった)。今回の
F-2ではさらに慎重な応答が支配的になり、3/4のケースでB役は**推測すらせず
「判定不能」と回答を拒否した**。

つまり自然言語条件での失敗モードは2種類ある:
1. **低confidenceで推測し、たまたま正解/不正解する**(実験Fケース1)
2. **判定を拒否する**(F-2の3ケース)

どちらのモードでも、B役は自分から「複数の解釈が成り立つ」と正しく認識していた
——これはAIが不注意だったのではなく、**入力自体が本当に曖昧だった**ことの
一貫した証拠になる。

## 意味一致・情報脱落の集計

| 指標 | 結果 |
|---|---|
| 自然言語、対象ファイルの一意な特定 | 1/4(明示的な表現のみ) |
| 自然言語、confidence「高い」 | 1/4 |
| 自然言語、複数解釈可能性「なし」 | 1/4 |
| AMP、対象ファイルの一意な特定 | (実験Cの論理から)4/4 |
| AMP、confidence「高い」 | (実験Fケース1から)1/1、かつ実験Cの収束により他3パターンも同一構造になるため実質4/4 |

## 意義

実験Fケース1(1ケース)では「正解率は同じでもconfidenceが違う」という
比較的穏やかな差だったが、F-2(4ケース)では**正解率自体に差が出た**
(自然言語1/4 vs AMP実質4/4)。これは実験Fの結果が偶然ではなく、**pronoun・
指示語を含む表現揺れという条件下では再現する性質**であることを示す、
2件目の独立した証拠になる。

ただし注意点: 4バリアントは全て「意図的に指示語を混ぜた」文であり、日常の
自然言語使用の中でどの程度の頻度でこの種の曖昧さが実際に発生するかは
未検証。また、AMP側は実験C・実験Fケース1の結果からの論理的な外挿であり、
F-2で改めて4パターン全てをAMPでも生成・解釈させたわけではない(実験Cが
「4つの自然言語→同一AMP構造」を保証しているため、追加検証の必要性は低いと
判断した)。
